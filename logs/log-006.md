**需求：** 用户执行 sql/fix_consume_from_pending_amount.sql 报 `ERROR: 42601 syntax error at or near "第"`（LINE 5 显示"第 4 行"）。

- 根因：原补丁含大量中文注释/字符串，粘贴到 Supabase SQL Editor 时中文按 GBK 误解为乱码，注释行被截断错位触发语法错误。

- 校验：文件 23086 字节 0 非 ASCII 字节；chr 序列经 Python 对照确认拼出正确中文；修正了"预收转消费"序列中把 消(28040) 误写为 费(36153) 的 bug。
