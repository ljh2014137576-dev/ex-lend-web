## 0017 · 2026-08-01 · 修复抽屉动画丢失（Tailwind 4 translate 属性）

**现象：** 修复点击拦截后，用户反馈抽屉滑入/滑出动画消失（瞬间跳变）。

**根因：** Tailwind 4 的 translate 工具类（-translate-x-full / translate-x-0）使用独立 CSS `translate` 属性，而非 `transform`。抽屉的过渡声明的是 `transition-[transform,visibility]`，transform 全程为 none，位移无过渡 → 动画失效。

**修复：** 过渡属性改为 `transition-[translate,visibility]`。

**验证（puppeteer 采样计算样式）：** 打开 translate 从 -19.5% → 0 平滑过渡；关闭 -62.9% → -100%，visibility 在动画结束后才隐藏。
